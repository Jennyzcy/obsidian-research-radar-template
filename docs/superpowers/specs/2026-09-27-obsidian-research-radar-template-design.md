# Obsidian 研究主页与论文雷达模板：设计说明

> 2026-09-27 范围修订：交付物从“通用最小模板”升级为“源 Vault 的完整可导入副本（脱敏版）”。本修订以当前实际 Vault 配置为准，不再以演示性插件清单或简化主页替代源界面。

## 目标

构建一个可公开发布的本地 Git 仓库。使用者下载后可直接将 `vault-template/` 作为 Obsidian Vault 打开，获得与源 Vault 一致的主题、插件、外观和主页组件；内容则是无私人笔记的可复用骨架。

## 成功标准

`vault-template/` 可被 Obsidian 直接打开；主页、主题和源 Vault 中现有的社区插件均离线随副本提供。使用者只需在 Obsidian 中确认社区插件信任；需要联网服务或个人授权的功能由使用者自行配置。

## 公开边界

仓库不包含私人笔记、附件、Copilot 会话、工作区状态、批注 sidecar、回收站、历史推送、论文配图、Zotero 数据、同步脚本、日历数据、绝对路径、项目 ID、密钥、令牌、Cookie 或密码。副本保留源 Vault 的主题、插件文件和外观配置；仓库同时记录第三方许可证与来源，公开发布前需人工确认各插件/主题的再分发许可。

## 分层结构

- `vault-template/`：从源 Vault 复制、经脱敏后的可直接打开副本。保留 `.obsidian/` 中与样式和功能有关的配置、插件、主题、主页和真实主页组件，以及通用模板和目录骨架。
- `docs/`：中文使用、隐私、许可证与二次定制说明。
- `scripts/`：可选的公开内容扫描和论文雷达安全辅助脚本；不要求使用者重新下载副本已经带有的主题或插件。
- `tests/`：验证目录骨架、配置完整性、来源不变、脱敏清单和公开内容扫描。

## 主页与视觉

主页使用源 Vault 的真实 DataviewJS 自定义视图和配套 CSS，保留其交互、结构和视觉风格。任何引用已移除私人文件的入口应改为通用目录或在缺少目标时安全降级，不得指向源 Vault 的绝对路径。

保留源 Vault 内的所有已安装主题（当前包括 Blue Topaz、AnuPpuccin 与 Things）以及当前外观配置；当前启用的主题与字体/强调色设置必须与源一致。保留自定义 CSS 片段，但不启用源 Vault 中未启用的片段。

## 插件与本机状态

副本保留源 Vault 当前安装的社区插件及其可公开设置：Calendar、Dataview、Editing Toolbar、Formatto、Image Converter、Modal Opener、Style Settings、BRAT 和 YH InkLight。仅保留可复用的插件配置；含本机路径、令牌、历史、缓存或个人内容的设置文件必须排除或改为安全默认值。`workspace.json`、`workspace-mobile.json`、`workspaces.json` 与图谱/临时界面状态不随副本发布。

Obsidian 的社区插件信任、Copilot 凭据和系统权限仍由每位使用者本人确认；副本不会尝试绕过这些边界。

## 论文雷达与定时推送

仅保留论文雷达的通用目录骨架、模板、中文操作说明和安全辅助脚本。历史推送、个人研究画像、已收集论文、Zotero 清单、附件和自动任务实例全部从副本移除。脚本负责日期和 ISO 周命名、拒绝同名覆盖、DOI/题名去重、预印本与正式版关联；周报只生成待审批清单，绝不自动写入 Zotero。

使用者可按中文说明在自己的 Codex Desktop 项目创建定时任务；仓库不会导出当前机器的自动任务 TOML、主机 ID、项目 ID 或原 Vault 路径。

## 验收

离线自动检查源 Vault 保留组件的文件哈希、当前主题与插件清单、主页引用路径、目录骨架，以及公开文件中是否出现原 Vault 路径或常见敏感字段。手动验收是直接在 Obsidian 打开 `vault-template/`，确认主页、主题和社区插件均可识别。

## 不可变性与替换边界

- 源 Vault `/Users/zcy/Library/Mobile Documents/iCloud~md~obsidian/Documents/学习记录` 为只读来源：不创建、修改、移动或删除其中的任何文件。
- 仅替换新仓库中的 `vault-template/`。仓库根目录的 `.obsidian/` 是本机使用状态，不纳入交付物，也不删除。
- 替换前在系统临时目录生成并扫描副本；扫描和验证通过后才替换交付目录。Git 历史保留此前简化模板，作为仓库内可恢复记录。
